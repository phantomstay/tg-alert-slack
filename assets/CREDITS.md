# Aircraft photo credits

Every photo in this directory comes from Wikimedia Commons under a licence that
allows reuse. Most are CC BY or CC BY-SA, which require the photographer to be
credited and, for BY-SA, that modified versions carry the same licence. The
files here are cropped to 1200x720 and re-encoded, which counts as modification.

Slack image blocks have nowhere to put a credit, so the attribution lives here
and should stay reachable: link this file from the channel topic or a pinned
message in #flight-pj-alerts.
